Exercice 3 - Déboguer une boucle

Programme A

Problème : la variable n n’est jamais modifiée dans la boucle. n > 0 reste toujours vraie → boucle infinie.

Correction : ajouter n = n - 1 dans le bloc de la boucle.

1n = 10
2while n > 0:
3    print(n)
4    n = n - 1

Programme B

Problème : la condition capital >= 1000 est toujours vraie puisque capital ne fait qu’augmenter → boucle infinie.

Correction : la condition devrait s’arrêter quand le capital dépasse l’objectif, donc while capital < 2000.

1capital = 1000
2while capital < 2000:
3    capital = capital * 1.05
4print(capital)

Programme C

Problème : compteur = compteur + 1 est hors de la boucle (non indenté). La condition compteur < 5 reste toujours vraie (compteur vaut toujours 0) → boucle infinie qui affiche “Bonjour” indéfiniment.

Correction : indenter compteur = compteur + 1 pour le mettre dans le bloc de la boucle.

1compteur = 0
2while compteur < 5:
3    print("Bonjour")
4    compteur = compteur + 1

1capital = 2000

⚠️ print ou return ? Ici on est dans le programme principal, pas dans une fonction : on utilise donc print pour afficher le résultat. À la question 3, la même logique est mise dans une fonction : on utilisera alors return, jamais print.

Q3.

1def annee(capital_initial, taux, objectif):
2    capital = capital_initial
3    annees = 0
4    while capital < objectif:
5        capital = capital * (1 + taux / 100)
6        annees = annees + 1
7    return annees

Q4. annee(2000, 2.5, 5000) → 38 ans
(le capital atteint alors ≈ 5 111.36 €)

⚠️ Attention au paramètre taux : la fonction attend 2.5 (le pourcentage), pas 0.025. C’est la ligne capital = capital * (1 + taux / 100) qui fait la conversion. Un appel annee(2000, 0.025, 5000) renverrait 3 666 ans !
