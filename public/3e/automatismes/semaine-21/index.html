Question
Quelle est la moyenne de la série statistique étudiée sur ce diagramme en barres ?

A. $3{,}5$   B. $4$   C. $3{,}375$   D. $2$
Il y a un total de $8$ valeurs.
La somme des valeurs : $3 \times 2+1 \times 3+3 \times 4+1 \times 6=27$.
La moyenne est : $\dfrac{27}{8}={\color{#EB7F73}\boldsymbol{3{,}375}}$.
La bonne réponse est la réponse C.

01
Question
Sur le plan du quartier de sa cousine, Yvette constate que $3~\text{mm}$ sur le plan correspond à $3~\text{m}$ dans la réalité.
Quelle est l'échelle du plan ?
$3~\text{m} = 3\,000~\text{mm}$. Donc $3~\text{mm}$ sur le plan représente $3\,000~\text{mm}$ dans la réalité.
L'échelle est $\dfrac{3}{3\,000}=\dfrac{1}{1\,000}$, donc ${\color{#EB7F73}\boldsymbol{\dfrac{1}{1\,000}}}$.
02
Question
On donne la série statistique suivante : $17$ ; $15$ ; $2$ ; $6$ ; $4$ ; $9$ ; $10$ ; $18$ ; $11$ ; $3$.
Parmi ces propositions, laquelle peut être la médiane de la série ?

A. $6{,}5$   B. $9$   C. $9{,}5$   D. $10$
Série triée : $2$ ; $3$ ; $4$ ; $6$ ; $9$ ; $10$ ; $11$ ; $15$ ; $17$ ; $18$.
Il y a $10$ valeurs (pair), la médiane est la moyenne des termes de rang $5$ et $6$ : $\dfrac{9 + 10}{2} = {\color{#EB7F73}\boldsymbol{9{,}5}}$.
La bonne réponse est la réponse C.

$\mathcal{A}_\text{triangle} = (b \times h) \div 2 = (3~\text{cm} \times 6~\text{cm}) \div 2 = {\color{#EB7F73}\boldsymbol{9}}~\text{cm}^2$
