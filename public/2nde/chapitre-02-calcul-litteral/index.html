      Calcul littéral (1)

      2.1 Simple et double distributivité

      Définitions
      Développer un produit signifie écrire ce produit sous la forme d'une somme (ou différence) de termes.
      Factoriser une somme signifie écrire cette somme sous forme d'un produit de facteurs.
      Propriété :
      Soient $a$, $b$ et $k$ trois réels :
      Exemples
      Développer les expressions suivantes :
      • $A = -3(-3a+1)$
        $\phantom{A} = -3\times(-3a)+(-3)\times 1$
        $\phantom{A} = {\color{#EA8556}9a-3}$
      • $B = -11(-4x-10)-(-10-6x)$
        $\phantom{B} = 44x+110-(-10-6x)$
        $\phantom{B} = 44x+110+10+6x$
        $\phantom{B} = {\color{#EA8556}50x+120}$
      • $C = 7x+10(7x+8)$
        $\phantom{C} = 7x+70x+80$
        $\phantom{C} = {\color{#EA8556}77x+80}$
      Exemples
      Factoriser, au maximum, les expressions suivantes :
      • $A = -35y-42y^2$
        $\phantom{A} = {\color{#EA8556}7y}\times(-5)-{\color{#EA8556}7y}\times 6y$
        $\phantom{A} = {\color{#EA8556}7y}(-5-6y)$
      • $B = {\color{#8A9CC1}x}{\color{#EA8556}(2x+1)}-{\color{#8A9CC1}2}{\color{#EA8556}(2x+1)}$
        $\phantom{B} = {\color{#EA8556}(2x+1)}{\color{#8A9CC1}(x-2)}$
      • $C = {\color{#EA8556}(3x+3)}{\color{#8A9CC1}(4x-2)}-{\color{#EA8556}(3x+3)}{\color{#8A9CC1}(5x-3)}$
        $\phantom{C} = {\color{#EA8556}(3x+3)}{\color{#8A9CC1}(4x-2-(5x-3))}$
        $\phantom{C} = {\color{#EA8556}(3x+3)}{\color{#8A9CC1}(4x-2-5x+3)}$
        $\phantom{C} = {\color{#EA8556}(3x+3)}{\color{#8A9CC1}(-x+1)}$
      Propriété :
      Soient $a$, $b$, $c$ et $d$ quatre réels :
      Exemples
      Développer les expressions suivantes :
      • $A = (z+3)(-5z+2)$
        $\phantom{A} = z\times(-5z)+z\times 2+3\times(-5z)+3\times 2$
        $\phantom{A} = -5z^2+2z+(-15z)+6$
        $\phantom{A} = -5z^2-13z+6$
      • $B = (-6k+1)(3k-2)$
        $\phantom{B} = -6k\times 3k+(-6k)\times(-2)+1\times 3k+1\times(-2)$
        $\phantom{B} = -18k^2+12k+3k+(-2)$
        $\phantom{B} = -18k^2+15k-2$
      • $C = -3(-10x+5)(9x+5)$
        $\phantom{C} = -3(-90x^2-50x+45x+25)$
        $\phantom{C} = -3(-90x^2-5x+25)$
        $\phantom{C} = 270x^2+15x-75$
      • $D = -4+(8x+10)(-9x-3)$
        $\phantom{D} = -4-72x^2-24x-90x-30$
        $\phantom{D} = -72x^2-114x-34$

      2.2 Identités remarquables

      Propriétés :
      Soient $a$ et $b$ deux réels alors :
      • $(a+b)^2 = a^2+2\times a\times b+b^2$
      • $(a-b)^2 = a^2-2\times a\times b+b^2$
      • $(a+b)(a-b) = a^2-b^2$
      Démonstration :
      En additionnant les aires, on en déduit que : $(a+b)^2 = {\color{#8A9CC1}a^2}+{\color{#E6B459}b^2}+2{\color{#D36740}ab}$
      On a la formule $(a-b)^2=a^2-2\times a\times b+b^2$ grâce à l'autre figure.
      Par ailleurs, par double distributivité, on a :
      $(a+b)(a-b)=a^2-ab+ba-b^2=a^2-b^2$.
      Exemples
      Développer les expressions suivantes :
      • $(2x-5)^2 = (2x)^2-2\times 2x\times 5+5^2$
        $\phantom{(2x-5)^2} = 4x^2-20x+25$
      • $(3x+7)^2 = (3x)^2+2\times 3x\times 7+7^2$
        $\phantom{(3x+7)^2} = 9x^2+42x+49$
      • $(9x-2)(9x+2) = (9x)^2-2^2$
        $\phantom{(9x-2)(9x+2)} = 81x^2-4$
      Exemples
      Factoriser les expressions suivantes :
      • $81x^2-108x+36 = (9x)^2-2\times 9x\times 6+6^2$
        $\phantom{81x^2-108x+36} = (9x-6)^2$
      • $64x^2+64x+16 = (8x)^2+2\times 8x\times 4+4^2$
        $\phantom{64x^2+64x+16} = (8x+4)^2$
      • $81x^2-81 = (9x)^2-9^2$
        $\phantom{81x^2-81} = (9x-9)(9x+9)$
      Exemple
      Développer, réduire et ordonner l'expression suivante : $A = (x+2)(4x-3)-x(7-x)^2$. On a : $$\begin{align*} A &= 4x^2-3x+8x-6-x(7^2-2\times 7\times x+x^2)\\ &= 4x^2+5x-6-x(49-14x+x^2)\\ &= 4x^2+5x-6-49x-14x^2-x^3\\ &= -x^3-10x^2-44x-6 \end{align*}$$

      2.3 Expressions fractionnaires

      Pour écrire la somme (ou la différence) de deux expressions fractionnaires sous forme d’un quotient, on les réduit au même dénominateur.

      Exemples
      Réduire les expressions suivantes sous la forme d'un unique quotient :
      Pour tout $x\in\mathbb{R}^*$, écrire l'expression sous la forme d'un quotient : $$\begin{align*} 3x+\dfrac{1}{x} &= \dfrac{3x^2}{x}+\dfrac{1}{x}\\ &= \dfrac{3x^2+1}{x} \end{align*}$$
      Pour $x\in\mathbb{R}\setminus\!\left\{\dfrac{3}{2}\right\}$, écrire l'expression sous la forme d'un quotient : $$\begin{align*} 4+\dfrac{4}{-2x+3} &= \dfrac{4(-2x+3)}{-2x+3}+\dfrac{4}{-2x+3}\\ &= \dfrac{-8x+12+4}{-2x+3}\\ &= \dfrac{-8x+16}{-2x+3} \end{align*}$$
