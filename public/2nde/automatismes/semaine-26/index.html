Semaine 26

Séance + Devoirs 12 questions ≈ 20 min

Six questions ouvertes — cherche d'abord, puis déplie la correction question par question.

01
Question
$20 \times 2 + 6 = \ldots$
Correction
$${\color{#4A5D7A}20 \times 2 + 6 = 46}$$
02
Question
$2 - 2\,026 = \ldots$
Correction
$${\color{#4A5D7A}2 - 2\,026 = -2\,024}$$
03
Question
Compléter l’égalité : $\ldots - 1 = 2\,026 + 2$
Correction
$2\,026 + 2 = 2\,028$, donc $\ldots = 2\,028 + 1 = {\color{#4A5D7A}2\,029}$
04
Question

Quel nombre doit-on ajouter à $2\,026$ pour obtenir l’abscisse de $A$ ?

Correction

Entre $2\,026$ et $2\,027$ il y a $5$ subdivisions, donc chaque subdivision vaut $\dfrac{1}{5}$.

$A$ est à la $2^{\text{e}}$ subdivision : on ajoute $\dfrac{2}{5} = {\color{#4A5D7A}0{,}4}$ à $2\,026$.

05
Question
Combien vaut $2\,026 + 20 - 6$ ?
Correction
$$2\,026 + 20 - 6 = 2\,046 - 6 = {\color{#4A5D7A}2\,040}$$
06
Question

$2\,026$ est-il un multiple de $2$ ?

$\square$ OUI $\quad$ $\square$ NON

Correction

$2\,026 = 2 \times 1\,013$, donc $2\,026$ est bien un multiple de $2$.

$${\color{#4A5D7A}\text{OUI}}$$
07
Question

Compléter la suite :

$20\text{h}\,26\text{min}$ ; $20\text{h}\,40\text{min}$ ; $20\text{h}\,54\text{min}$ ; $\ldots\text{h}\,\ldots\text{min}$

Correction

La raison est $14\text{ min}$. Le terme suivant est $20\text{h}\,54\text{min} + 14\text{min} = 21\text{h}\,08\text{min}$.

$${\color{#4A5D7A}21\text{h}\,08\text{min}}$$
08
Question
Compléter : $\sqrt{2\,026} \times \ldots = 2\,026$
Correction
$\sqrt{2\,026} \times \sqrt{2\,026} = 2\,026$, donc la réponse est ${\color{#4A5D7A}\sqrt{2\,026}}$.
09
Question
Quel est le plus grand entier multiple de $5$ strictement inférieur à $2\,026$ ?
Correction

$2\,025 = 5 \times 405$, donc $2\,025$ est multiple de $5$ et $2\,025 < 2\,026$.

$${\color{#4A5D7A}2\,025}$$
10
Question
Compléter : $2\,026 \times 10^{\ldots} = 2{,}026$
Correction
$2\,026 \times 10^{-3} = 2\,026 \div 1\,000 = 2{,}026$, donc l’exposant est ${\color{#4A5D7A}-3}$.
11
Question
Écrire sous forme décimale : $\dfrac{2\,000}{10} + \dfrac{26}{100}$
Correction
$$\dfrac{2\,000}{10} + \dfrac{26}{100} = 200 + 0{,}26 = {\color{#4A5D7A}200{,}26}$$
12
Question
Écrire le plus simplement possible : $\dfrac{2\,026}{-1}$
Correction
$$\dfrac{2\,026}{-1} = {\color{#4A5D7A}-2\,026}$$
13
Question
Le périmètre d’un triangle isocèle est $4\,226\text{ cm}$. La base mesure $2\,026\text{ cm}$. Que mesurent les deux côtés égaux ?
Correction

Les deux côtés égaux ont pour longueur :

$$\dfrac{4\,226 - 2\,026}{2} = \dfrac{2\,200}{2} = {\color{#4A5D7A}1\,100\text{ cm}}$$
14
Question
Calculer $4 \times 2{,}026 \times 25$.
Correction
$$4 \times 2{,}026 \times 25 = (4 \times 25) \times 2{,}026 = 100 \times 2{,}026 = {\color{#4A5D7A}202{,}6}$$
15
Question
Réduire : $2\,026x - 6x$
Correction
$$2\,026x - 6x = (2\,026 - 6)x = {\color{#4A5D7A}2\,020x}$$
16
Question
Quel est le plus petit entier relatif appartenant à l’intervalle $\left]-2\,026\,;\,2\,026\right]$ ?
Correction

$-2\,026$ est exclu (intervalle ouvert en $-2\,026$), donc le plus petit entier relatif est :

$${\color{#4A5D7A}-2\,025}$$
17
Question

Nous sommes le $29$ décembre $2025$. Il est $1\text{h}$ du matin.

Combien d’heures faut-il attendre avant de pouvoir se souhaiter la nouvelle année $2026$ (à minuit le $1^{\text{er}}$ janvier $2026$) ?

Correction
  • Reste du 29 déc. (de 1h à minuit) : $23\text{h}$
  • 30 déc. : $24\text{h}$
  • 31 déc. : $24\text{h}$

Total : $23 + 24 + 24 = {\color{#4A5D7A}71\text{ heures}}$

18
Question
En multipliant un nombre positif par lui-même, on trouve $2\,026$. Quel est ce nombre ?
Correction

Le nombre positif dont le carré est $2\,026$ est :

$${\color{#4A5D7A}\sqrt{2\,026}}$$
19
Question
Calculer $R$ sachant que : $\dfrac{1}{R} = 1 - \dfrac{2}{2\,026}$
Correction
$$\dfrac{1}{R} = \dfrac{2\,026}{2\,026} - \dfrac{2}{2\,026} = \dfrac{2\,024}{2\,026}$$$${\color{#4A5D7A}R = \dfrac{2\,026}{2\,024}}$$
20
Question
Calculer : $\dfrac{2}{2\,026} + \dfrac{1}{4\,052}$
Correction
$$\dfrac{2}{2\,026} + \dfrac{1}{4\,052} = \dfrac{4}{4\,052} + \dfrac{1}{4\,052} = {\color{#4A5D7A}\dfrac{5}{4\,052}}$$
21
Question
Calculer $AB$ dans le triangle rectangle $ABC$ (angle droit en $B$) avec $AC = \sqrt{2\,026}$ et $BC = 6$ (voir le livret).
Correction

On applique le théorème de Pythagore :

$$AB^2 = AC^2 - BC^2 = (\sqrt{2\,026})^2 - 6^2 = 2\,026 - 36 = 1\,990$$$${\color{#4A5D7A}AB = \sqrt{1\,990}}$$
22
Question
Je pense à un nombre. Je le multiplie par $100$, puis j’ajoute $326$ et j’obtiens $2\,026$. Quel est ce nombre ?
Correction
$$100n + 326 = 2\,026 \implies 100n = 1\,700 \implies n = {\color{#4A5D7A}17}$$
23
Question

Soit $f$ la fonction linéaire vérifiant $f(2\,026) = -4\,052$.

Compléter : $f(x) = \ldots$

Correction

$f$ est linéaire : $f(x) = ax$. Donc $a = \dfrac{-4\,052}{2\,026} = -2$.

$${\color{#4A5D7A}f(x) = -2x}$$
24
Question
Exprimer la somme de $a$ et $2\,026$ en fonction de $a$.
Correction
$${\color{#4A5D7A}a + 2\,026}$$
25
Question
Déterminer l’antécédent de $2\,026$ par la fonction $f$ définie par $f(x) = -3x + 2\,023$.
Correction

On résout $f(x) = 2\,026$ :

$$-3x + 2\,023 = 2\,026 \implies -3x = 3 \implies x = {\color{#4A5D7A}-1}$$
26
Question
$f(x) = x^2 + 2\,026$. Calculer $f(-5)$.
Correction
$$f(-5) = (-5)^2 + 2\,026 = 25 + 2\,026 = {\color{#4A5D7A}2\,051}$$
27
Question
Donner la solution de l’équation : $-3x + 1\,999 = 2\,026$
Correction
$$-3x = 2\,026 - 1\,999 = 27 \implies x = \dfrac{27}{-3} = {\color{#4A5D7A}-9}$$
28
Question
Calculer $(-1)^{2\,026} + (-1)^{2\,025}$.
Correction

$2\,026$ est pair : $(-1)^{2\,026} = 1$.

$2\,025$ est impair : $(-1)^{2\,025} = -1$.

$$1 + (-1) = {\color{#4A5D7A}0}$$
29
Question

Un antécédent de $2\,026$ par la fonction $f$ est $2\,025$. Compléter l’égalité correspondante.

$f(\ldots) = \ldots$

Correction
$${\color{#4A5D7A}f(2\,025) = 2\,026}$$
30
Question

Pour remplir $20$ bouteilles d’huile d’olive, Stéphane utilise $100\text{ kg}$ d’olives.

Combien va-t-il remplir de bouteilles pleines avec $2\,026\text{ kg}$ d’olives ?

Correction

$1$ bouteille nécessite $100 \div 20 = 5\text{ kg}$.

$2\,026 = 405 \times 5 + 1$, donc Stéphane peut remplir ${\color{#4A5D7A}405}$ bouteilles.
