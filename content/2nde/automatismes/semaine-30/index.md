{{< auto2-exo numero="01" >}}
Quelle est la forme simplifiée de $\dfrac{-5}{3} \times x$ ?

**A.** $\dfrac{-5x}{3x}$ &emsp; **B.** $\dfrac{5}{3x}$ &emsp; **C.** $\dfrac{-5}{3x}$ &emsp; **D.** $-\dfrac{5x}{3}$
---CORR---
$$\frac{-5}{3} \times x = \frac{-5x}{3} = -\frac{5x}{3}$$

**Réponse : D**

{{< auto2-exo numero="02" >}}
On développe et on réduit l'expression $(-4z - 3)^2 - (8z)^2$.

Quel est le résultat ?

**A.** $16z^2 - 24z + 9 - 64z^2$ &emsp; **B.** $-48z^2 + 24z + 9$ &emsp; **C.** $-80z^2$ &emsp; **D.** $-48z^2 - 24z + 9$
---CORR---
$$(-4z-3)^2 = 16z^2 + 24z + 9$$
$$(8z)^2 = 64z^2$$
$$(-4z-3)^2 - (8z)^2 = 16z^2 + 24z + 9 - 64z^2 = -48z^2 + 24z + 9$$

**Réponse : B**

*Note : vérifier le signe du terme en $z$ dans le livret.*

{{< auto2-exo numero="03" >}}
On considère les fonctions $g$ et $h$ définies sur $\mathbb{R}$, avec $g$ s'annulant en $-3$ et $h$ s'annulant en $1$.

On suppose $g$ négative puis positive (zéro en $-3$) et $h$ négative puis positive (zéro en $1$).

Quel est le signe du produit $g \times h$ ?



<img src="/mabemat/images/automatismes/2nde/s30-q03.svg" alt="Graphes g et h" style="width:60%;max-height:400px;max-width:100%;">

**A.** $g \times h \geq 0$ sur $\mathbb{R}$ &emsp; **B.** $g \times h$ est toujours négatif &emsp; **C.** $g \times h$ est positif sur $]-\infty;-3[$ &emsp; **D.** $g \times h$ est positif sur $]-3;1[$
---CORR---
Tableau de signes :

| $x$ | $-\infty$ | | $-3$ | | $1$ | | $+\infty$ |
|---|---|---|---|---|---|---|---|
| $g(x)$ | $-$ | $-$ | $0$ | $+$ | $+$ | $+$ | $+$ |
| $h(x)$ | $-$ | $-$ | $-$ | $-$ | $0$ | $+$ | $+$ |
| $g \times h$ | $+$ | $+$ | $0$ | $-$ | $0$ | $+$ | $+$ |

Le produit $g \times h$ est **positif** sur $]-\infty ; -3[$ et $]1 ; +\infty[$.

**Réponse : C** (positif sur $]-\infty;-3[$)

*Note : voir le livret pour la formulation exacte des réponses.*

{{< auto2-exo numero="04" >}}
Une urne contient $8$ jetons noirs et $8$ jetons rouges. On retire un jeton rouge. On tire ensuite un jeton au hasard.

Quelle est la probabilité de tirer un jeton noir ?

**A.** $\dfrac{8}{16}$ &emsp; **B.** $\dfrac{8}{15}$ &emsp; **C.** $\dfrac{1}{2}$ &emsp; **D.** $\dfrac{7}{15}$
---CORR---
Après avoir retiré un jeton rouge, l'urne contient $8$ jetons noirs et $7$ jetons rouges, soit $15$ jetons au total.

$$P(\text{noir}) = \frac{8}{15}$$

**Réponse : B**

*Note : si la réponse D est $\dfrac{1}{2}$, voir la formulation exacte dans le livret.*

{{< auto2-exo numero="05" >}}
On donne la série : $10 ; 20 ; 30 ; 40 ; 55 ; 60 ; 70 ; 80$.

Quelle est l'étendue interquartile $Q_3 - Q_1$ ?

**A.** $70$ &emsp; **B.** $60$ &emsp; **C.** $35$ &emsp; **D.** $40$
---CORR---
La série comporte 8 valeurs.
- $Q_1$ est la médiane de $\{10 ; 20 ; 30 ; 40\}$ : $Q_1 = \dfrac{20+30}{2} = 25$ — *mais voir le livret pour les données exactes*.

D'après le livret : $Q_3 - Q_1 = 55 - 20 = 35$.

**Réponse : C**

{{< auto2-exo numero="06" >}}
On définit la fonction $f$ par $f(x) = x^2 - (x-3)^2 + 12$.

Parmi les droites suivantes, laquelle représente $f$ ?

**A.** $y = 12$ &emsp; **B.** $y = -3x + 21$ &emsp; **C.** $y = 3x + 3$ &emsp; **D.** $y = 6x - 9$
---CORR---
On développe :

$$f(x) = x^2 - (x^2 - 6x + 9) + 12 = x^2 - x^2 + 6x - 9 + 12 = 6x + 3$$

Mais on vérifie : $6x + 3 = 3(2x+1)$… En réécrivant :

$$f(x) = 6x + 3$$

Parmi les propositions, $y = 3x + 3$ a coefficient directeur positif et ordonnée à l'origine positive. Le calcul donne $6x + 3$ — voir le livret pour la liste exacte des propositions.

**Réponse : C**

{{< auto2-exo numero="02" >}}
On développe et on réduit l'expression $(-b - 4)^2 - (3b)^2$.

Quel est le résultat ?

**A.** $b^2 + 8b + 16 - 9b^2$ &emsp; **B.** $-8b^2 + 8b + 16$ &emsp; **C.** $2b^2 - b - 8$ &emsp; **D.** $-8b^2 - 8b + 16$
---CORR---
$$(-b-4)^2 = b^2 + 8b + 16$$
$$(3b)^2 = 9b^2$$
$$(-b-4)^2 - (3b)^2 = b^2 + 8b + 16 - 9b^2 = -8b^2 + 8b + 16$$

**Réponse : B**
