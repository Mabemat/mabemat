{{< auto2-exo numero="01" >}}
Écrire sous la forme d'une fraction la plus simple possible : $\dfrac{1}{2a}+\dfrac{6}{b}$
---CORR---
$$\dfrac{1}{2a}+\dfrac{6}{b}=\dfrac{1 \times b}{2a \times b}+\dfrac{6 \times 2a}{b \times 2a}=\mathbf{\dfrac{b+12a}{2ab}}$$
{{< /auto2-exo >}}

{{< auto2-exo numero="02" >}}
Écrire sous la forme d'une fraction la plus simple possible : $\dfrac{x}{8}\times \dfrac{3}{y}$
---CORR---
$$\dfrac{x}{8}\times \dfrac{3}{y}=\dfrac{x\times 3}{8\times y}=\mathbf{\dfrac{3x}{8y}}$$
{{< /auto2-exo >}}

{{< auto2-exo numero="03" >}}
On considère l'égalité $\dfrac{1}{U}=1+\dfrac{5}{7}$. Calculer $U$.
---CORR---
$$\dfrac{1}{U}=1+\dfrac{5}{7} = \dfrac{7}{7} + \dfrac{5}{7} =\dfrac{12}{7}$$

L'inverse de $U$ vaut $\dfrac{12}{7}$, donc $U=\mathbf{\dfrac{7}{12}}$.
{{< /auto2-exo >}}

{{< auto2-exo numero="04" >}}
Choisir deux nombres puis calculer l'inverse du carré de leur somme.

Le résultat obtenu si on choisit comme nombres $-4$ et $-1$ est :
---CORR---
La somme de $-4$ et $-1$ est : $-5$.

Le carré de cette somme est : $(-5)^2=25$.

L'inverse de ce carré est : $\mathbf{\dfrac{1}{25}}$.
{{< /auto2-exo >}}

{{< auto2-exo numero="05" >}}
Simplifier l'écriture fractionnaire : $\dfrac{5x-35}{5}$
---CORR---
$$\dfrac{5x-35}{5}=\dfrac{5(x-7)}{5}=\mathbf{x-7}$$
{{< /auto2-exo >}}

{{< auto2-exo numero="06" >}}
Parmi $\mathbb{R}$, $\mathbb{Q}$, $\mathbb{D}$, $\mathbb{Z}$ et $\mathbb{N}$, quel est le plus petit ensemble de nombres auquel appartient $-8{,}59$ ?
---CORR---
$-8{,}59$ est un nombre décimal (il s'écrit avec un nombre fini de chiffres après la virgule). Le plus petit ensemble de nombres auquel il appartient est donc $\mathbf{\mathbb{D}}$.

Rappel : $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{D} \subset \mathbb{Q} \subset \mathbb{R}$
{{< /auto2-exo >}}

{{< auto2-exo numero="01" >}}
Écrire sous la forme d'une fraction la plus simple possible : $\dfrac{x}{7}\times \dfrac{10}{y}$
---CORR---
$$\dfrac{x}{7}\times \dfrac{10}{y}=\dfrac{x\times 10}{7\times y}=\mathbf{\dfrac{10x}{7y}}$$
{{< /auto2-exo >}}

{{< auto2-exo numero="02" >}}
Écrire sous la forme d'une fraction la plus simple possible : $\dfrac{3}{8a}+\dfrac{1}{b}$
---CORR---
$$\dfrac{3}{8a}+\dfrac{1}{b}=\dfrac{3 \times b}{8a \times b}+\dfrac{1 \times 8a}{b \times 8a}=\mathbf{\dfrac{3b+8a}{8ab}}$$
{{< /auto2-exo >}}

{{< auto2-exo numero="03" >}}
On considère l'égalité $\dfrac{1}{y}=4-\dfrac{1}{9}$. Calculer $y$.
---CORR---
$$\dfrac{1}{y}=4-\dfrac{1}{9} = \dfrac{36}{9} - \dfrac{1}{9} =\dfrac{35}{9}$$

L'inverse de $y$ vaut $\dfrac{35}{9}$, donc $y=\mathbf{\dfrac{9}{35}}$.
{{< /auto2-exo >}}

{{< auto2-exo numero="04" >}}
Choisir deux nombres puis calculer l'inverse de leur somme.

Le résultat obtenu si on choisit comme nombres $4$ et $-1$ est :
---CORR---
La somme de $4$ et $-1$ est $3$.

Son inverse est : $\mathbf{\dfrac{1}{3}}$.
{{< /auto2-exo >}}

{{< auto2-exo numero="05" >}}
Simplifier l'écriture fractionnaire : $\dfrac{9x+36}{9}$
---CORR---
$$\dfrac{9x+36}{9}=\dfrac{9(x+4)}{9}=\mathbf{x+4}$$
{{< /auto2-exo >}}

{{< auto2-exo numero="06" >}}
Parmi $\mathbb{R}$, $\mathbb{Q}$, $\mathbb{D}$, $\mathbb{Z}$ et $\mathbb{N}$, quel est le plus petit ensemble de nombres auquel appartient $14$ ?
---CORR---
$14$ est un entier naturel. Le plus petit ensemble de nombres auquel il appartient est donc $\mathbf{\mathbb{N}}$.

Rappel : $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{D} \subset \mathbb{Q} \subset \mathbb{R}$
{{< /auto2-exo >}}
