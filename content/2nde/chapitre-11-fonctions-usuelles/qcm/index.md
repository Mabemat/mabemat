{{< qcm correct="1" >}}
---Q---
La fonction inverse $f(x) = \dfrac{1}{x}$ est définie sur :
- $\mathbb{R}$
- $\mathbb{R} \setminus \{0\}$
- $[0\,;+\infty[$
- $\mathbb{R}^+$
---CORR---
On ne peut pas diviser par $0$, donc $x=0$ est la seule valeur interdite.

$$D_f = \mathbb{R} \setminus \{0\} = ]-\infty\,;0[\,\cup\,]0\,;+\infty[$$
{{< /qcm >}}

{{< qcm correct="2" >}}
---Q---
Le minimum de la fonction carrée $f(x) = x^2$ est :
- $1$
- $-\infty$
- $0$
- Il n'existe pas
---CORR---
Un carré est toujours positif ou nul : $x^2 \geqslant 0$ pour tout réel $x$.

L'égalité $x^2 = 0$ est atteinte pour $x = 0$, donc le minimum vaut $0$.
{{< /qcm >}}

{{< qcm correct="1" >}}
---Q---
La fonction carrée $f(x) = x^2$ est décroissante sur :
- $[0\,;+\infty[$
- $]-\infty\,;0]$
- $\mathbb{R}$
- $]-\infty\,;+\infty[$
---CORR---
La fonction carrée est décroissante sur $]-\infty\,;0]$ puis croissante sur $[0\,;+\infty[$.

Elle n'est donc pas monotone sur $\mathbb{R}$ tout entier.
{{< /qcm >}}

{{< qcm correct="1" >}}
---Q---
Sur $]0\,;+\infty[$, la fonction inverse est :
- Croissante
- Décroissante
- Constante
- Nulle
---CORR---
Si $0 < a < b$, alors $\dfrac{1}{a} - \dfrac{1}{b} = \dfrac{b-a}{ab} > 0$, donc $\dfrac{1}{a} > \dfrac{1}{b}$.

L'ordre est inversé : la fonction est décroissante sur $]0\,;+\infty[$ (et aussi sur $]-\infty\,;0[$).
{{< /qcm >}}

{{< qcm correct="1" >}}
---Q---
$f(x) = \dfrac{1}{x}$ pour $x = -2$ vaut :
- $2$
- $-\dfrac{1}{2}$
- $\dfrac{1}{2}$
- $-2$
---CORR---
$$f(-2) = \dfrac{1}{-2} = -\dfrac{1}{2}$$

L'inverse d'un nombre négatif reste négatif.
{{< /qcm >}}

{{< qcm correct="1" >}}
---Q---
L'axe de symétrie de la parabole d'équation $y = x^2$ est :
- L'axe des abscisses
- L'axe des ordonnées
- La droite $y = x$
- La droite $x = 1$
---CORR---
Pour tout réel $x$, $f(-x) = (-x)^2 = x^2 = f(x)$.

Deux valeurs opposées ont la même image : la courbe est symétrique par rapport à l'axe des ordonnées.
{{< /qcm >}}

{{< qcm correct="2" >}}
---Q---
La courbe de $y = \dfrac{1}{x}$ est symétrique par rapport à :
- L'axe des abscisses
- L'axe des ordonnées
- L'origine $O$
- La droite $y = x$
---CORR---
Pour tout $x \neq 0$, $f(-x) = \dfrac{1}{-x} = -\dfrac{1}{x} = -f(x)$.

Deux valeurs opposées ont des images opposées : l'hyperbole est symétrique par rapport à l'origine $O$.
{{< /qcm >}}

{{< qcm correct="1" >}}
---Q---
Résoudre $\dfrac{1}{x} = 3$ (avec $x \neq 0$) :
- $x = 3$
- $x = \dfrac{1}{3}$
- $x = -3$
- $x = -\dfrac{1}{3}$
---CORR---
$$\dfrac{1}{x} = 3 \iff 1 = 3x \iff x = \dfrac{1}{3}$$

Vérification : $\dfrac{1}{\frac{1}{3}} = 3$. On a bien $S = \left\{\dfrac{1}{3}\right\}$.
{{< /qcm >}}

{{< qcm correct="2" >}}
---Q---
Résoudre $x^2 = 25$ dans $\mathbb{R}$ :
- $x = 5$
- $x = -5$
- $x = 5$ ou $x = -5$
- Pas de solution dans $\mathbb{R}$
---CORR---
$$x^2 = 25 \iff x^2 - 25 = 0 \iff (x-5)(x+5) = 0$$

Un produit est nul si l'un de ses facteurs est nul, donc $x = 5$ ou $x = -5$.

$$S = \{-5\,;5\}$$

L'erreur classique est de ne garder que la solution positive : $25$ a bien deux racines opposées.
{{< /qcm >}}

{{< qcm correct="3" >}}
---Q---
Résoudre $x^2 = -4$ dans $\mathbb{R}$ :
- $x = 2$
- $x = -2$
- $x = 2$ ou $x = -2$
- Pas de solution réelle
---CORR---
Pour tout réel $x$, $x^2 \geqslant 0$. Or $-4 < 0$.

Aucun carré ne peut être négatif, donc $S = \varnothing$.

À ne pas confondre avec $x^2 = 4$, qui admet $x = 2$ ou $x = -2$.
{{< /qcm >}}
