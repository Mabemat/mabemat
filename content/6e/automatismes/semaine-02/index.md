Comment note-t-on la droite qui passe par les points $A$ et $B$ ?
---CORR---

{{< auto6-exo num="Question 3" >}}
---Q---
Donner le triple de $25$ et le quart de $60$.

{{< auto6-exo num="Question 4" >}}
---Q---

---CORR---
${\color{#D36740}\boldsymbol{2}}$
{{< /auto6-exo >}}

{{< auto6-exo num="Question 1" >}}
---Q---
Placer un point $D$ qui n'est pas aligné avec $C$ et $G$.
<br>
<img src="6auto-droite-cg.svg" alt="Les points C et G" style="display:block;margin:0.8rem auto;max-width:100%">
---CORR---
$D$ est placé <span class="rep">en dehors de la droite $(CG)$</span>.
{{< /auto6-exo >}}

{{< auto6-exo num="Question 2" >}}
---Q---
Que signifie « $C \in (d)$ » ?
---CORR---
<span class="rep">Le point $C$ appartient à la droite $(d)$.</span>
{{< /auto6-exo >}}

{{< auto6-exo num="Question 3" >}}
---Q---
Le double d'un nombre vaut $48$. Combien vaut son quart ?
---CORR---
${\color{#D36740}\boldsymbol{6}}$
{{< /auto6-exo >}}

{{< auto6-exo num="Question 4" >}}
---Q---
Écrire le nombre égal à $30$ dizaines et $14$ unités.
---CORR---
${\color{#D36740}\boldsymbol{314}}$
{{< /auto6-exo >}}

{{< auto6-exo num="Question 5" >}}
---Q---
Calculer mentalement : $500 - 137 = \ldots$
---CORR---
$500 - 137 = {\color{#D36740}\boldsymbol{363}}$
{{< /auto6-exo >}}
