{{< auto1-exo numero="02" >}}
Ranger dans l'ordre croissant les trois nombres suivants :

$$A=0{,}375\qquad B=\dfrac{38}{100}\qquad C=\dfrac{7}{20}$$
---CORR---
Pour comparer ces trois nombres, on les écrit sous forme décimale :
$A = 0,375$<br>

$B = \dfrac{38}{100} = 0,38$<br><br>

$C = \dfrac{7}{20} = \dfrac{7 \times 5}{20\times 5} = \dfrac{35}{100}=0,35$<br><br>

On a donc : $0,35 < 0,375 < 0,38$.
Finalement : $\boldsymbol{C < A < B}$.
{{< /auto1-exo >}}

$3a\times 1-a=3a-a=\boldsymbol{2a}$

{{< auto1-exo numero="05" >}}
Soit $h$ la fonction définie par $h(x)=-6x+3$.

Calculer $h(-3)+h(1)$.
---CORR---
On a : $h(-3)=-6\times (-3)+3=21$ et $h(1)=-6\times 1+3=-3$. <br>

On en déduit que $h(-3)+h(1)=21-3=\boldsymbol{18}$.

{{< auto1-exo numero="06" >}}
Donner le premier quartile de la série statistique suivante :

$$5\ ;\ 17\ ;\ 14\ ;\ 6\ ;\ 20\ ;\ 23\ ;\ 8\ ;\ 16\ ;\ 15$$
---CORR---
La série triée par ordre croissant est : $5$ ; $6$ ; $8$ ; $14$ ; $15$ ; $16$ ; $17$ ; $20$ ; $23$. <br>
La série contient $9$ valeurs. <br>

Pour trouver le rang de $Q_1$, on calcule le quart de 9 qui vaut
$\dfrac{9}{4}=2{,}25$ <br>
On arrondit à l'entier supérieur qui vaut $3$. <br>
Le premier quartile est donc la valeur de rang $3$ de la série classée : $Q_1=8$.

---Q---
Voici la représentation graphique d'une fonction $f$ définie sur $[-3\ ;\ 6]$.

<img src="graphe_f04_3_devoir.svg" alt="Graphe" style="display:block;margin:1rem auto;max-width:360px">

Une seule affirmation est correcte :

- Le maximum de $f$ est $6$.
- $f(-0{,}2) \times f(-1{,}3) < 0$
- L'inéquation $f(x) \leqslant 0$ a pour ensemble de solutions $[-3\ ;\ -2[\cup]-2\ ;\ 2]$.
- $f$ est positive sur $[3{,}3\ ;\ 5{,}9]$

---CORR---
$\bullet$ $f$ est positive sur $[3{,}3\,;\,5{,}9]$<br>
Cette affirmation est correcte : <br>
$f$ est positive sur $[3{,}3\,;\,5{,}9]$ car la courbe se situe au-dessus de l'axe des abscisses sur cet intervalle.<br>
$\bullet$ L'inéquation $f(x) \leqslant 0$ a pour ensemble de solutions $[-3\,;\,-2[\cup]-2\,;\,2]$.<br>
Cette affirmation est fausse : <br>
Les solutions de l'inéquation $f(x) \leqslant 0$ sont les abscisses des points de la courbe situés en dessous ou sur l'axe des abscissses.<br>
$\bullet$ Le maximum de $f$ est $6$.<br>
Cette affirmation est fausse : <br>
Le point le plus haut de la courbe a pour ordonnée $3$. C'est le maximum de $f$.<br>
$\bullet$ $f(-0{,}2) \times f(-1{,}3) < 0$<br>
Cette affirmation est fausse : <br>
$f(-0{,}2) <0$ et  $f(-1{,}3) < 0$, donc le produit est positif.

La bonne réponse est la réponse <span class="rep">D</span>.
{{< /qcm >}}

{{< auto1-exo numero="02" >}}
Ranger dans l'ordre croissant les trois nombres suivants :

$$A=\dfrac{6}{10}\qquad B=\dfrac{31}{50}\qquad C=0{,}59$$
---CORR---
Pour comparer ces trois nombres, on les écrit sous forme décimale :<br>
$A = \dfrac{6}{10} = 0,6$

$B = \dfrac{31}{50} = \dfrac{31 \times 2}{50\times 2} =  \dfrac{62}{100}=0,62$

$C = 0,59$

On a donc : $0,59 < 0,6 < 0,62$.<br>
Finalement : $\boldsymbol{C < A < B}$.

Calculer $k(0)+k(3)$.
---CORR---

On en déduit que $k(0)+k(3)=-5+13=\boldsymbol{8}$.
